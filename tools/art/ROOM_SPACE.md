# 房间空间与家具重构

2026-09-07。用户反馈：背景模糊，希望房型统一且能看见侧墙，家具能够贴合墙面。

## 现状证据

- `ref_room_cut.py` 从总览图裁切背景，再经 img2img 输出 1344×768。总览下午区域仅约 591×231，季节小图约 191×113；放大后的像素尺寸不等于真实细节。
- `Room.jsx` 使用独立背景图片与自由拖动的方形物件图片；没有墙面、桌面或家具底部接触点数据。
- CSS 背景没有 blur；仅改 CSS 锐化不能恢复缺失的绘画细节。

## 统一空间规范

- 保留日式 RPG 奇幻、古朴木作、鼠尾草绿、旧黄铜和清晰现代动画质感。
- 16:9 固定镜头，主墙居中，左右侧墙均可见，轻微俯视、浅单点透视。
- 地面约占画面下方 43%，墙角、窗框、消失点保持固定；季节版本只改变窗外景色、色温和光影。
- 每张运行背景单独生成高清原图，目标至少 1920×1080；禁止从总览小图放大作为正式素材。
- `room-space-concept.png` 是带家具的空间示意，不能直接用作可装修房间背景，否则家具会被烘焙进背景并与可购物家具重复。

## 家具与摆放

- 书柜、衣柜、壁炉：后墙、左墙、右墙使用对应朝向的独立绘制素材。不能将正面图做 CSS 斜切来冒充侧视图。
- 桌椅、床：按同一镜头绘制，明确脚底锚点与地面占地范围；靠墙时让家具背部接触线匹配墙脚线。
- 地毯：地面层，使用对应地面透视。
- 壁画与挂钟：墙面层，不按地面脚底排序。
- 茶壶、书本、花瓶：可选择桌面或窗台锚点，随承载家具移动。
- 交互提供“自由 / 靠后墙 / 靠左墙 / 靠右墙”，仅向有对应朝向素材的家具开放方向选项。接近合法接触线时显示吸附提示；仍可自由调整。
- 接触阴影与物件绘制光向一致；地面物件与伙伴按脚底深度统一排序。

## 接入顺序与验收

1. 先用家具空间概念稿确认房型、留白和透视，不修改玩家存档。
2. 以确定房型生成空房母版，再派生季节版本，逐张检查墙角和地面接缝。
3. 优先重绘书柜、壁炉、桌子三件，验证三种墙面方向与地面摆放后扩展全套。
4. 配置物件可见边界、脚底、贴墙接触点与可承载表面，再接入吸附和遮挡。
5. 保留购买 ID 与既有布局；仅新增或主动整理时采用新推荐布局。
6. 验收必须在房间实际显示尺寸检查清晰度、脚底对齐、靠墙无缝隙、拖动不漂浮、季节切换不造成家具错位。

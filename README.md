# Chess Puzzle Training

A chess enthusiast’s hobby project for their child, with puzzles supplied by the
project author. Includes AI-generated artwork. See [sources](SOURCES.md).

## Run locally

```sh
npm install
npm run dev
```

For a production build: `npm run build`, then `npm run preview`.
Windows users can also use **Play Chess Puzzle Training.bat**.

Progress is saved in your browser. Use **Save files** to export or import a `.sav`.

Run checks with `npm test`.
